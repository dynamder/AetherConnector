# AetherConnector

[ENGLISH](./README-en.md) [简体中文](./README.md)

一个模拟社交媒体交互体验的AI聊天程序，专注于生成拟人化的角色扮演对话

## 声明 Notice

- 本项目**不计划**接入任何真实运行的第三方社交平台 API（例如微信、QQ、Discord）。
- AetherConnector **并非设计为**具备专家级任务执行能力的代理（Agent）。其核心定位是流畅，拟人化的**对话交互**，而非提供精确的研究分析、复杂代码生成或自动化工作流执行。
